# 普通群话题内的快捷设置

普通群会话话题内，原有操作按钮下增加两项：

- **同步到群：开/关**：最终回复是否同时发送到话题外的群消息；进度仍只在话题内。
- **群聊复用：开/关**：后续群消息是否默认延续同一个会话；关时走新会话，已有话题不迁移。

点击保存后，原卡立即显示最新状态，正文及其它按钮保留。仅有操作权限的用户可修改。
配置只影响当前机器人和当前群，保存到 data 目录的 `regular-group-settings.json`，重启后保留。
未设置时沿用原有配置。私聊、话题群、话题外群消息和无会话操作的通知卡不增加按钮。
显式 `/t`、`/topic` 或主人要求新开会话仍按原规则处理。

以私有权限写入 `regular-group-card-snapshots`，用于点击后的无损刷新。
已超出保留范围的旧卡会提示使用最新会话卡，不会覆盖原按钮或修改配置。
