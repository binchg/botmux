# 普通群的连续会话

普通群话题外默认按「机器人 + 群」复用一个会话。主人直接发消息即可追加要求；其他成员需要明确 @ 机器人，原有访问权限检查仍生效。忙碌时消息追加到当前会话，不会自动创建第二个 Codex 会话。

只有主人在消息开头明确说「新开一个会话，任务内容」，或使用 `/t 任务内容`、`/topic 任务内容`，才会创建独立话题和会话。条件、否定、引用中的“新开会话”不会触发。

已有话题内、话题群和私聊的路由与免 @ 设置保持原样。历史会话不会被删除或合并。群会话创建期间严格串行；轮到下一条消息时重新检查会话，防止连续消息重复创建。

`regularGroupOwnerContinuation` 默认开启。仅在明确需要恢复旧策略时，在对应机器人配置设为 `false`；届时旧的 `regularGroupReplyMode`、`regularGroupMentionMode` 同时恢复对话题外入口的控制。开启新默认策略时，这些旧设置仅保留原话题内的行为，不再导致话题外自动分叉或允许其他人免 @。
